# Examples

* https://docs.vllm.ai/en/v0.20.0/examples/

vLLM's examples are split into three categories:
vLLM 的示例分为三类:

- If you are using vLLM from within Python code, see the [Offline Inference](https://github.com/vllm-project/vllm/tree/main/examples/offline_inference) section.
  如果您在 Python 代码中使用 vLLM, 请参阅[离线推理](https://github.com/vllm-project/vllm/tree/main/examples/offline_inference)部分.

- If you are using vLLM from an HTTP application or client, see the [Online Serving](https://github.com/vllm-project/vllm/tree/main/examples/online_serving) section.
  如果您正在从 HTTP 应用程序或客户端使用 vLLM, 请参阅[在线服务](https://github.com/vllm-project/vllm/tree/main/examples/online_serving)部分.

- For examples of using some of vLLM's advanced features (e.g. LMCache or Tensorizer) which are not specific to either of the above use cases, see the [Others](https://github.com/vllm-project/vllm/tree/main/examples/others) section.
  有关使用 vLLM 的一些高级功能(例如 LMCache 或 Tensorizer)的示例(这些功能并非上述任何用例所特有), 请参阅[其他](https://github.com/vllm-project/vllm/tree/main/examples/others)部分.
