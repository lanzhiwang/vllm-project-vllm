# PagedAttention

* https://huggingface.co/docs/text-generation-inference/conceptual/paged_attention

LLMs struggle with memory limitations during generation. In the decoding part of generation, all the `attention keys and values` generated for previous tokens are stored in GPU memory for reuse. This is called `KV cache`, and it may take up a large amount of memory for large models and long sequences.
LLM 在生成过程中会受到内存限制的影响. 在生成的解码阶段, 之前生成的所有`注意力键和值`都会存储在 GPU 内存中以供重用. 这被称为 `KV 缓存`, 对于大型模型和长序列而言, 它可能会占用大量内存.

`PagedAttention` attempts to optimize memory use by partitioning the KV cache into blocks that are accessed through a lookup table. Thus, the KV cache does not need to be stored in contiguous memory, and blocks are allocated as needed. The memory efficiency can increase GPU utilization on memory-bound workloads, so more inference batches can be supported.
PagedAttention 通过将键值缓存划分为多个块, 并利用查找表进行访问, 来优化内存使用. 因此, 键值缓存无需存储在连续内存中, 而是根据需要分配内存块. 这种内存效率的提升可以提高内存密集型工作负载的 GPU 利用率, 从而支持更多推理批次.

The use of a lookup table to access the memory blocks can also help with KV sharing across `multiple generations`. This is helpful for techniques such as `parallel sampling`, where multiple outputs are generated simultaneously for the same prompt. In this case, the cached KV blocks can be shared among the generations.
使用查找表访问内存块也有助于跨多个世代共享键值对 (KV). 这对于`并行采样`等技术非常有用, 因为在并行采样中, 同一个 prompt 会同时生成多个输出. 在这种情况下, 缓存的键值对可以在不同世代之间共享.

TGI's(text-generation-inference) PagedAttention implementation leverages the custom cuda kernels developed by the [vLLM Project](https://github.com/vllm-project/vllm). You can learn more about this technique in the [project's page](https://vllm.ai/).
TGI 的 PagedAttention 实现利用了 vLLM 项目开发的自定义 CUDA 内核. 您可以在该项目的页面上了解更多关于这项技术的信息.
